## Implementation

A bounded owner-only `network_settings`/`configure_network` API validates complete direct IP/provider PeerIDs and delegates encrypted CAS persistence to Core. All fallible configuration construction and the durable write precede live mutation. A fresh swarm retires old protocol handlers and pending request IDs while preserving core, private IPC, transport key and assigned listener ports. Durable outbox work resumes with the original ciphertext/operation. Same-value retry does not reconnect again. Saved client preferences override client defaults on restart; operator-only relay/AutoNAT server flags and quotas remain separate.

Relay first hops are explicitly connected with a new TCP port before ordinary circuit use, avoiding a macOS TIME_WAIT tuple after reconnect; DCUtR retains its separate coordinated upgrade policy. Relay-only can reply over an already authenticated incoming circuit even if the peer's record only lists direct routes. AutoNAT holds a success response within its original probe deadline until the matching authenticated callback arrives; neither event alone publishes a route.

The native bridge exposes only the two explicit owner commands. The panel saves on explicit action, polls actual diagnostics, keeps the original form revision until save/reload, and compares values independently of JSON field order. It distinguishes a saved provider address from a confirmed route. No service opt-in, arbitrary state write, owner signing or agent permission is added.
