# Actionable agent failure responses

Follow-up to working bounded MCP discovery, required for practical retries: current daemon maps every CoreError to unauthorized, making an occupied inbox or changed idempotency key indistinguishable from revoked credentials.

Contract before implementation: shared serializable AgentFailure has code, safe message, retryable and optional details. InboxBusy becomes inbox_busy/retryable true; expired/replaced ack becomes inbox_lease_expired/false; first item over page limit becomes inbox_item_too_large/false/details{requiredBytes}; accepted operation reused with changed input becomes idempotency_conflict/false for both inbox and send. Permission, invalid proof and unknown scope remain opaque unauthorized/false with no details. Adapter/daemon availability failure is unavailable/true with no path, SQL or key diagnostics. Cancellation is cancelled/false. retryable means the same request may succeed after the condition clears; it is not an instruction to spin. Expired leases require a new poll ID; oversized pages require corrected bounds within the grant; conflicts require original intent or a new ID.

Implementation target: shared failure DTO/classification in crates/core, the signed-agent branch in node runtime and existing MCP cancellation/availability wrapping. Owner IPC error contract remains unchanged. Actual authorization and transactions are unchanged.

Tests first: two real process/MCP tests in support/mcp_errors.rs. Real peer ciphertexts are received and read with actual leases/cursors. Too-small page corrects without a lost item; busy runtime retries after sibling ack; conflicting poll retains original page; expired lease recovers the exact item through sibling runtime. Denials expose no details. A second test uses legacy MCP and actual daemon kill/restart: send conflict, retryable outage, exact previously committed ID on same live MCP after restart, then new peer message. Malformed signed input remains opaque.

A third test injects an actual SQLCipher trigger failure during outgoing commit. Both MCP and signed IPC report unavailable/true without the trigger's private diagnostic; nonce/registry/MLS/history/operations/outbox persist unchanged.
