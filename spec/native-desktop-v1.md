# Native Tauri bridge and first desktop flow

Tauri2.11.5 uses the actual React production frontend and the existing DesktopHost/daemon client. WebView commands are exactly snapshot, create_identity, create_invitation, add_contact and send_message. Commands take the frontend's existing `{request: ...}` payload and return actual core DTOs/errors; no copied state machine or fabricated messages. Core updates are forwarded as `core:changed` so the existing React subscription reloads network/receipt/incoming state.

Use explicit Tauri app-command manifests and a local capability for the main window only. No remote origins, secondary untrusted windows, filesystem/shell/arbitrary signing or owner-token exposure. CSP disallows frames/objects/external scripts; navigation remains local. The root identity/SQLCipher key and owner token stay in Rust/OS keychain. Endpoint hints and error messages contain public metadata only.

The first native integration tests use Tauri's MockRuntime for the actual invoke routing/permissions and independent real daemon child processes for all core/P2P/MLS work. They verify profile creation/invalid input, real invite, two-daemon text/receipt/idempotency flow, unknown-command denial and inability of a secondary window or foreign invocation origin to mutate the profile. These are native command integration tests, not a claim that WKWebView E2E or the entire V1 is complete.

Actual WKWebView automation runs against hidden test-only windows, with screenshots inspected. Official Tauri documentation supports macOS via the embedded tauri-plugin-wdio-webdriver server (1.3.0), so no visible browser or focus stealing is needed. The optional e2e feature is forbidden in release builds. The packaged debug .app has passed the two-user UI flow including detached daemon delivery and reopen; the ad-hoc signed release bundle contains the same frontend and sibling daemon lookup with no automation dependency. scripts/check-native.mjs reproduces this gate. Remaining R=10, relay/NAT, group finality, broker/MCP, jobs/credentials/reviews/economy and complete E01–E26 stay open.
